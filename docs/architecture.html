Architecture

Isolated modules, Pcap2HDL-style. Changing the trace path does not rebuild. Changing HDL or DPI sources does.

Trace (.log / .csv) │ ▼ dpi/tlp_reader.c open · parse · pack 4 beats · C tallies │ ▼ DPI-C tb_tlp_dpi.sv AXIS driver tdata/tvalid/tready/tstart/tlast │ ├──► tlp_header_parser.sv hdr_* on last beat └──► tlp_match_tracker.sv complete / open / matched │ ▼ Scoreboard HDL counters ≟ get_c_*() → mis=0 │ ▼ simulation_trace.vcd

Modules

Match semantics

Aligned with pcieshark:

Hint / eventMeaning
match_hint = 1QEMU one-line cfg access → complete
MemRd without completeOpens a tag/requester slot
CplCloses a matching slot → matched; else unmatched
CfgWrNo completion pair expected

What this is not

Not a PCIe PHY, PIPE, or commercial VIP. The AXIS-TLP bus is a teaching and bring-up abstraction so TLPs can be observed like AXIS bytes in L2AxisBr and gated like packets in Pcap2HDL. 
make gate
# [SUM] HDL  CfgRd=25 CfgWr=1 … complete=26
# [SUM] C    CfgRd=25 CfgWr=1 … complete=26
# [GATE] mis=0  PASS
